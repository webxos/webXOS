About FIRMBOT

FIRMBOT is a free, zero-server OSINT firmware analyst by WebXOS. It runs entirely in your browser and speaks to you in plain language.

How it works

When you drop a firmware file, FIRMBOT reads it locally, computes MD5/SHA-1/SHA-256, extracts strings (ASCII + UTF-16LE), detects versions, infers vendors, and measures block entropy. Only derived metadata — never the file itself — is used to query public sources.

External data sources

  • GitHub REST API — repository and release discovery
  • GitLab API — project and release discovery
  • NVD CVE API — vulnerability correlation
  • MAC Vendors — hardware vendor lookup from OUI (with offline fallback)

Privacy

No firmware bytes are uploaded. No telemetry is collected. API keys you provide are held in this browser session's memory and are sent only to the intended API origin.

Limitations

Not a malware scanner, a flasher, or vendor support. Findings are heuristic — treat them as leads. Community firmware may contain modifications; verify checksums before flashing. MAC Vendors may be blocked by CORS in some browsers; FIRMBOT falls back to a bundled OUI prefix table for common vendors.
