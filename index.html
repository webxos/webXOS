SEC/01 — THE INDEX PAGE

WHAT THIS PAGE IS

You are looking at the single-file landing page for webXOS 2027 — a browser-native operating environment for the edge. This file is not a marketing site or a download page. It is the front door to a complete system: a full windowed desktop that boots from this same HTML document when you launch the sandbox, plus a structured set of notes on how everything is assembled and where the rest of the project lives.

Everything interactive — the terminal, file manager, text editor, markdown forge, raster console, hardware survey, session manager — lives inside the popup triggered by the Launch Desktop button. This page itself stays deliberately static: no backend, no tracking, no external state. The three sections below — About, Pathways, Architecture — exist to orient you before you step into the sandbox or out to the wider project.

SEC/03 — DESIGN NOTES

ARCHITECTURE & PRIVACY

The privacy posture is not a policy — it is a consequence of how the system is assembled. There is no endpoint to call, so there is nothing to log.

NO ACCOUNT

There is no sign-up, no login, no session token. Identity is irrelevant to every code path.

NO COOKIES

Nothing is written to cookies. Preferences use localStorage; the sandbox file system uses IndexedDB.

NO TELEMETRY

No analytics, no beacons, no error reporting endpoints. The hardware survey reads browser APIs and renders them in-tab only.

NO SERVER CALLS

Core modules never open a network connection. Fonts are the only optional external fetch, and the app degrades gracefully without them.
