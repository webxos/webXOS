▣ HELP — PROTEINSIM 95

PROTEINSIM 95 — a 60 fps protein formation studio

A 1995-styled, draggable multi-window simulator for growing procedural protein structures with full Hugging Face dataset export.

Windows

  • VIEWER — live Three.js scene (drag window title bar to move, corner to resize).
  • CTRL — fold type, max residues, growth speed, auto-capture.
  • TELEM — live readouts of residue count, bonds, FPS, draw calls.
  • TERM — command terminal. Try help inside it.
  • DATA — build a Hugging-Face dataset (parquet + PNGs).
  • INFO — legend and shortcuts.

Using the terminal

  • run / pause / stop — control growth
  • type helix|sheet|coil|mixed — change fold
  • capture — take a snapshot
  • hf — export the current protein as a Hugging-Face dataset (parquet + PNG)
  • status — print state summary
  • reset — reset protein (keeps dataset)
  • clear — clear the terminal log

Hugging Face dataset export

The DATA window builds a proper HF dataset with the following structure:

  • data/train-00000-of-00001.parquet — one row per residue, with protein_id, aa_type, x/y/z, chain, timestamp (falls back to .jsonl if the parquet writer is unavailable).
  • images/sample_XX_frame_YY.png — snapshot PNGs.
  • README.md — HF frontmatter + column descriptions.
  • dataset_info.json — feature schema and citation block.

Load it into datasets with load_dataset("path/to/unzipped").

Performance

Designed for 60 fps on older hardware:

  • Pre-allocated GPU buffers — no per-frame geometry recreation.
  • Reduced particle counts and no post-processing.
  • Pixel ratio capped, antialias disabled at LOW quality.
  • CRT overlay is off by default (toggle with the CRT menu button).

Shortcuts

  • SPACE — start / pause
  • R — reset protein
  • 1–4 — switch fold
  • C — toggle CRT
  • H — toggle this help
  • L — reset window layout
